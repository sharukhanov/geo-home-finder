# Бэклог проекта Fatera

Список задач простыми словами: что уже сделано и что планируем.

---

## ✅ Готово

- Проект запущен в интернете (Railway), доступен по ссылке.
- Поиск по адресу и добавление точек кликом по карте.
- Расчёт зон, где удобно жить (пересечение зон доступности точек).
- Кнопка «Сбросить всё» — очистить точки и начать заново.
- База данных: добавленные точки сохраняются и не пропадают после обновлений.

---

## 🔜 В планах (по приоритету)

### 1. Точность расчёта — «сколько реально ехать»
Сейчас время до точки считается приблизительно (по прямой линии).
Задача: считать по-настоящему — с учётом дорог, метро и транспорта.
Это главная ценность сервиса: чем точнее зоны, тем полезнее продукт.

### 2. Аккаунты пользователей 👤
Дать возможность регистрироваться и входить в свой личный кабинет,
чтобы у каждого были свои сохранённые точки и результаты поиска.
Сейчас данные общие для всех — это временно.

### 3. Удобство и внешний вид
- Редактирование уже добавленных точек (не только добавить/удалить).
- Выбор города (сейчас карта настроена на Москву).
- Более красивое отображение зон на карте.
- Удобная работа с телефона.

### 4. Тестирование и надёжность
- Автоматические проверки, чтобы ничего не ломалось при изменениях.
- Стабильная работа поиска адресов под нагрузкой.

### 5. Взросление продукта
- Свой красивый адрес сайта вместо технического.
- Резервные копии базы, безопасность.
